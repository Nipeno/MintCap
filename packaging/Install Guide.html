How to install

✓ Pure mode friendly

Pure mode blocks modified game files. MintCap isn't one - it's a ReShade add-on, and FiveM has built-in support for loading ReShade, so it runs on pure-mode servers.

Server rules still come first: if a server bans ReShade outright, that covers this too.

  1. Open your FiveM plugins folder.

    Press Win+R, paste this, press Enter: 
    %localappdata%\FiveM\FiveM.app\plugins
    A folder window opens - leave it open.

    Nothing opened / error? Then FiveM isn't in the default spot. Open your FiveM install folder instead (the one with FiveM.exe) and go into FiveM.app\plugins inside it.

  2. Drag the add-on files into that folder.

    In the zip, open the Copy-these-into-plugins folder. Drag its three files - dxgi.dll, MintCap.addon64, Enable-ReShade.bat - into the plugins folder.

    Already have ReShade? (NVE, QuantV, other graphics pack)

    Don't drag dxgi.dll - that is ReShade, and you already have it. Just drag the other two files and leave your existing ReShade completely alone.

    ReShade can be installed under a few different file names (dxgi.dll, d3d11.dll and others) - whichever yours uses, you don't need to touch it.

    Drag the files themselves, not the folder - all three should sit directly inside the plugins folder, not inside a sub-folder.

  3. Allow ReShade in FiveM (one time).

    In the plugins folder you just filled, double-click Enable-ReShade.bat. It sets everything up by itself - press a key to close it.
    • Blue "Windows protected your PC" box? Click More info → Run anyway. (The source is public - open it in Notepad first if you like.)
    • Says it couldn't find FiveM? See If the .bat can't find FiveM below.

  4. Start FiveM and join a server.

  5. Turn the limiter ON.

    Press Home to open the ReShade menu. (Some setups use Insert instead - if Home does nothing, try Insert.) First time, ReShade shows a tutorial pop-up: click Continue or Skip Tutorial. Find the "MintCap" window and set FPS cap to the number you want - or click one of the presets. 0 means unlimited (no cap at all).

    ✓ Done - your choice is saved for next time.

MintCap is a plain ReShade add-on, so it works in any game ReShade runs on. It needs the add-on-enabled build of ReShade - the standard build won't load add-ons at all.

Two things in the zip you can ignore here: the folder named Copy-these-into-plugins (that name is for a different install path - the files inside are the same ones) and Enable-ReShade.bat, which fixes a problem your game doesn't have.

  1. Get ReShade with add-on support into your game.

    Easiest way: run the official installer from reshade.me, pick your game, and choose the build with full add-on support.

    Already have add-on-enabled ReShade in that game? Skip this step entirely and leave it alone.

    Or use the ReShade in this zip

    The dxgi.dll in the zip is add-on-enabled ReShade. Copy it next to your game's .exe - but the correct name depends on the graphics API the game uses: dxgi.dll (DX10-12), d3d11.dll, d3d12.dll, d3d9.dll or opengl32.dll. Rename it to match your game's API.

    The installer picks that name for you, which is why it's the easier route.

  2. Put MintCap.addon64 next to the ReShade file.

    ReShade looks for add-ons in its own folder - the same folder as the ReShade .dll, which for most games is the folder holding the game's .exe. Drop MintCap.addon64 in there.

    Using a custom location? ReShade reads AddonPath under [ADDON] in ReShade.ini - if that's set, the add-on goes there instead.

  3. Start the game and turn the limiter ON.

    Press Home to open the ReShade menu (some setups use Insert). Find the "MintCap" window and set FPS cap to the number you want - or click a preset. 0 means unlimited (no cap at all).

    ✓ Done - your choice is saved for next time.

Which number should I pick?

0 means unlimited - the add-on stays out of the way. Any number above 0 is the frame rate it holds you to.

  • GTA: its physics is tied to frame rate, so cars handle differently at different FPS. Racing servers commonly ask everyone to sit at 60 for exactly that reason - if you're on one, use the number the server asks for.
  • Otherwise, match your monitor (60, 144, 240...): frames your screen can't show are wasted work.
  • A steady lower number often feels smoother than an unsteady high one. If your FPS swings between 80 and 140, capping at 80 can beat both.

Already have ReShade but don't see the window?

Good news: you almost certainly don't need to replace anything. This add-on works with any ReShade from 6.1 onwards, which covers current graphics packs. Just make sure MintCap.addon64 is sitting in your plugins foldernext to your ReShade .dll and leave the rest of your setup exactly as it is.

If ReShade's menu has no Add-ons tab at all, your ReShade was installed without add-on support - reinstall it with the add-on build and nothing else changes.

If the "MintCap" window still doesn't show up, first make sure you tried Home and Insert, then open ReShade.log in your FiveM.app foldernext to the ReShade .dll and look near the top for a line like:

Failed to register add-on, because the requested API version (11) is not supported (N)!

That means your ReShade is older than 6.1. The best fix is to update your graphics pack - current versions ship a recent ReShade, and that keeps everything else about your setup intact. Update ReShade to a current version and everything else stays as it is.

If you'd rather update ReShade by hand: Important - ReShade isn't always called dxgi.dll. Depending on how it was installed the file may be named dxgi.dll, d3d11.dll, d3d12.dll, d3d9.dll or opengl32.dll. Look in your plugins folderyour game's folder to see which one you have.

Then take the zip's dxgi.dll (from the Copy-these-into-plugins folder), copy it in and rename it to match the file you already have, replacing it. Renaming matters: dropping a dxgi.dll next to an existing d3d11.dll does nothing, because the old one still loads first. It's the latest official ReShade and still runs graphics packs fine.

Back up the file you're replacing first, so you can put it back if anything misbehaves.

If the .bat can't find FiveM (manual allow)

Only needed if Enable-ReShade.bat couldn't locate FiveM. The first time you launch with ReShade, FiveM's console shows red text like:

Blocked load of ReShade version 5 or higher ...
add the following section to <path>\CitizenFX.ini:
   [Addons]
   ReShade5=ID:xxxxxxxx acknowledged that ReShade 5.x has a bug...
  1. Fully close FiveM.
  2. Open the file it named - CitizenFX.ini, in your FiveM.app folder (the console shows the exact path).
  3. Add the two lines exactly as your own console showed them: 
    [Addons]
ReShade5=ID:xxxxxxxx acknowledged that ReShade 5.x has a bug that will lead to game crashes
    The ID (xxxxxxxx) is unique to your PC - copy it from your own console, not this example.
  4. Save and start FiveM again.

How to use

  • Press Home (or Insert) to open/close the ReShade menu.
  • In the "MintCap" window: type a number in FPS cap, or click a preset. It applies instantly.
  • 0 = unlimited. Click Off to remove the cap without closing anything.
  • Your choice is saved and stays set next launch.
  • Turn VSync off in-game. The limiter and VSync each wait for their own timing, and running both together can stack those waits into stutter or an effective 30 FPS. Use one or the other - this add-on instead of VSync.

How to uninstall

  1. Close FiveM.
  2. Close the game.
  3. Open %localappdata%\FiveM\FiveM.app\plugins.
  4. Open the folder holding the ReShade .dll (usually your game's folder).
  5. Delete MintCap.addon64.
  6. Only if you installed ReShade just for this and want it gone too, also delete the ReShade file you added - dxgi.dll if you used our zip. If a graphics pack put ReShade there (under whatever name), leave it alone.

Bans and server rules are your risk. MintCap loads into a running game process. Many games, platforms, servers and anti-cheat systems don't allow that, and the only people who decide are the ones running them - you could be kicked, suspended or permanently banned, and lose access to a game or an account.
